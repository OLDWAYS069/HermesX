# HermesOne 128×64 鍵盤與警示排版

## 原因與修改

- 五排鍵盤在標題、草稿之後只剩約 34 px，每排不足 7 px；英文字與框線重疊，注音被縮至約 4 px。
- 小螢幕鍵盤以頁面顯示兩排、每排 10 個字元（每頁 20 個）；同頁旋鈕只移動上下排的游標。上排最左往前切上一頁，下排最右往後切下一頁。注音使用原始 12×12 glyph，既有鍵值、大小寫、注音組字及 EXIT/DEL/OK 操作維持原路徑。
- 草稿只使用單行並保持尾端可見；候選文字不再自動換行蓋住下一列。
- 警示共用 `HermesXCompactUi`：標題在 y=0，分隔線 y=14，正文 y=17/31，底部按鈕 y=48、高 16 px。單行區域不允許隱式換行。
- 詳情內容按完整行捲動，最後一頁不跨越正文邊界；更新長訊息以兩行一頁輪流顯示。

## 功能清單

128×64 的功能清單使用 13 px 標題區與四個 12 px 選項列。`返回` 仍是第一個可選項，
因此 ONLINE、MSG Recent Send、GROUP、Finder 與 TraceRoute 等資料清單可同時顯示三筆內容；
Fast Setup、TAK 設定／頻道及節點詳細資料使用相同的四列視窗與游標捲動規則。
鍵盤的兩排 10+10 字元與彈窗兩行正文不屬於功能清單，維持原有排版。

HermesOne 未建立的獨立 Hermes EM UI module 不作為現行彈窗實作；EM 警告由
`Screen::drawEmergencyConfirmOverlay()` 進入本次修正的 renderer。
