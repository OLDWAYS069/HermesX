# MSG 注音輸入

HermesX 的 `ONLINE` 與 `GROUP` 節點詳情頁共用同一套 `MSG` 編輯器；現在可在原本英文鍵盤與大千注音鍵盤之間切換。

## 操作方式

- 英文鍵盤的 `Aa`：維持原有功能與位置，切換英文大寫／小寫。
- 英文鍵盤的 `中`：進入注音鍵盤。
- 注音鍵盤的 `EN`：回到英文鍵盤；先前選擇的 `Aa` 大小寫狀態會保留。
- 注音鍵盤的 `Aa`：也可預先切換回到英文時要使用的大小寫。
- 注音鍵盤的 `˙`：完成目前音節並標記為輕聲。
- `SP`：尚未組字時輸入空白；正在組字時，以一聲完成目前音節。
- `OK`：正在組字時開啟候選字頁；沒有組字時送出訊息。
- `DEL`：優先刪除目前注音組字；沒有組字時刪除草稿最後一個完整 UTF-8 字元。
- 候選字頁第一項是 `返回鍵盤`；選取候選字後會加入草稿並回到鍵盤。
- `EXIT`、Cancel 或 Back：離開編輯器並回到原本的 ONLINE／GROUP 詳情頁。

若裝置有實體 ASCII 鍵盤，注音模式也接受大千鍵位；空白鍵是一聲，Enter 開啟候選字。

## 實作範圍

- 注音核心與精簡詞庫位於 `src/graphics/hermesx_input/`。
- 移植來源、版本與第三方授權列於 `src/graphics/hermesx_input/README.md` 及 `licenses/hermesx-zhuyin/`。
- 本版採精簡詞庫，保留既有 OTA app slot；未搬入上游約 2.5 MB 的完整詞庫。
- 功能只接入直接 MSG 編輯器，不改變罐頭訊息的頻道、收件人或傳送語意。
