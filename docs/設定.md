# HermesOne 0.1.0 設定

HermesOne 同時保留 Meshtastic App 設定及 HermesX 裝置端設定 UI。各模組的實際編譯狀態以功能矩陣為準。

## 建議使用的設定

- `Region`：台灣選 `TW`，未設定地區前 LoRa 不會正常發射。
- LoRa preset、頻道與裝置 Role：由 Meshtastic App 設定後重新啟動確認。
- BLE：用於 App 配對與資料同步。
- 裝置名稱與 Short Name：可由 App 修改，首頁會顯示 Short Name。
- 罐頭訊息：可由 App 設定文字與目標頻道，再由旋鈕操作。

## 裝置端可測試項目

- UI 與旋鈕方向
- 螢幕相關選項
- 蜂鳴器開關
- LoRa 基本設定頁
- 頻道與節點資料頁
- 罐頭訊息入口

這些頁面仍需逐項實機確認；重要通訊設定修改後，建議重新啟動並用 App 讀回驗證。

## 不適用 HermesOne 0.1.0

- MQTT
- 獨立 Hermes EM UI 執行緒
- Wi-Fi 設定、URL 更新、Wi-Fi OTA
- Waypoint、Range Test、Neighbor Info
- 環境、動作與電源遙測感測器設定
- Heltec Tracker TFT 與 Direct TFT 動畫設定

GPS、TAK/TAK Tracker、GROUP PIN、Lighthouse/Finder、Fast Setup 與更新 UI 均保留；WS2812B 使用 P0.06，GPS 模組 TX 使用 P1.06/D10。

## 更新韌體

HermesOne 沒有 Wi-Fi 更新模式，也不使用 ESP32 的 `firmware.bin` / `firmware.factory.bin`。更新方式是雙擊 Reset 進入 UF2 bootloader，再複製 `firmware.uf2`。

完整狀態請見 [HermesOne_FEATURE_MATRIX.md](HermesOne_FEATURE_MATRIX.md)。
